## `// ABOUT`

> Lamess UI is a custom **Hyprland desktop environment** built from scratch.
> Minimal. Functional. Terminal-aesthetic. Always dark.
>
> Inspired by retro CRT terminals and cyberpunk interfaces —
> designed for people who treat their desktop as a tool, not a toy.

<br/>

## `// PHILOSOPHY`

```
  We build TUI-first.

  Every solution starts as a terminal application — fast, keyboard-driven,
  composable. No unnecessary GUIs. No bloat. Just the terminal and the task.

  TUI tools are the foundation. The desktop is built on top of them.
```

## `// DESIGN PRINCIPLES`

```
  [01]  DARK MODE ONLY          —  No light theme. Ever.
  [02]  TRANSPARENCY + BLUR     —  Layered depth, glassy surfaces
  [03]  MONOSPACE EVERYTHING    —  Terminal-first typography
  [04]  ORANGE ACCENT           —  #FF6B00 as the single accent color
  [05]  SHARP BORDERS           —  1px precision lines, no heavy shadows
  [06]  MINIMAL ANIMATIONS      —  Functional motion only
  [07]  TUI FIRST               —  Every tool starts in the terminal
```
